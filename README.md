# CROSSAIR-Ultimate-Object-Creator-PRO
Smart Object Creator PRO is a Unity Editor tool designed to speed up GameObject creation and component setup.

Instead of manually adding physics, colliders, joints and renderers one by one, you can create or modify objects using simple component blueprints.

The tool supports both 2D and 3D workflows and allows you to quickly configure objects for gameplay prototyping, level design, testing and production setup.

Features:
• 2D / 3D mode switch
• Component blueprint workflow
• Create new GameObjects
• Apply components to selected objects
• Load components from selected objects
• Rigidbody / Rigidbody2D support
• Collider support
• Joint support
• Renderer support
• Undo support
• Lightweight editor-only implementation

Perfect for:
• Unity developers
• Level designers
• Technical artists
• Game prototyping
• Scene setup
• Workflow automation

No runtime dependencies.
Editor-only tool.
